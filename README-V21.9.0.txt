RADAR V21.9.0

Esta atualização adiciona o primeiro fluxo de criação de sites por descrição.

Teste local:
1. npm install
2. Configure ADMIN_PANEL_SECRET e OPENROUTER_API_KEY.
3. npm start
4. Abra o painel, autentique-se e use “Criar site a partir de uma descrição”.
5. Revise textos, itens, contatos e imagens antes de salvar/publicar.

Para imagens originais, mantenha CLOUDFLARE_API_TOKEN e CLOUDFLARE_ACCOUNT_ID com permissão Workers AI.
Para persistência em produção, mantenha SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY.
Não substitua as variáveis já existentes no Render.
