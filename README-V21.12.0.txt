RADAR DE CLIENTES — V21.12.0
EVOLUÇÃO DO GERADOR E EDITOR DE SITES

BASE
Esta versão parte diretamente da V21.11.0. Envie o conteúdo da pasta Radar-V21.12.0 para a raiz do repositório conectado ao Render, preservando as variáveis de ambiente existentes.

NOVIDADES
1. O gerador adapta a organização e a linguagem ao tipo de negócio.
2. Cada projeto pode conter frase de destaque, texto próprio para a seção Sobre, destaques e perguntas frequentes.
3. A prévia e o site publicado exibem esses conteúdos.
4. O editor manual permite alterar a frase de destaque e o texto Sobre.
5. A edição por conversa com IA pode alterar também destaques e perguntas frequentes. As alterações aparecem na prévia; revise e salve.

SEGURANÇA
A chave OpenRouter permanece no servidor. O modelo retorna dados estruturados; HTML, CSS e JavaScript fornecidos pela IA não são executados.
