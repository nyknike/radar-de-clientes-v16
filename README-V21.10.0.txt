RADAR DE CLIENTES — V21.10.0

Esta versão inicia a evolução do cardápio sobre a V21.9.3-CORRIGIDO enviada pelo usuário.

NOVA BASE DO CARDÁPIO
No editor de sites, abra a aba Conteúdo para gerenciar produtos. Cada produto agora pode:
- Ser marcado como disponível ou indisponível.
- Ter controle de estoque ativado ou desativado.
- Receber uma quantidade disponível.

No site público, produtos marcados como indisponíveis ou com estoque controlado e quantidade zero deixam de aparecer no cardápio.

COMPATIBILIDADE
Produtos antigos são tratados como disponíveis e sem controle de estoque, para preservar os catálogos já existentes. Nenhuma variável de ambiente ou integração foi alterada.

AINDA NÃO INCLUÍDO
A baixa automática de estoque após confirmação do pedido, personalização avançada (tamanhos, sabores, bordas e adicionais) e checkout próprio serão desenvolvidos nas próximas etapas. O WhatsApp continua sendo o fluxo principal existente.

APLICAÇÃO
Extraia o ZIP e envie o conteúdo da pasta Radar-V21.10.0 para a raiz do repositório GitHub conectado ao Render. Faça commit e acompanhe o deploy. Não altere variáveis de ambiente.

Esta entrega foi validada localmente; não foi publicada no Render.
